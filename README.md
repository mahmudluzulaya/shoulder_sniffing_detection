This project is a Shoulder Surfing Detection System developed in Python using a camera-based approach. The application activates the device’s camera and continuously monitors the video feed to detect the number of people visible in front of the screen.

If the system detects more than one person (two or more faces) in the camera frame, it assumes a potential shoulder surfing risk. In response, the application automatically:

Blurs the screen to protect sensitive information

Plays a warning beep sound to alert the user

When only one person is detected, the screen remains clear and the system continues normal operation.

The goal of this project is to enhance privacy and prevent unauthorized viewing of sensitive information in public or shared environments, such as offices, classrooms, or public spaces.
